⌨️ Commands

Run TypeScript only in a folder whose package.json lists typescript (ts-lab/ or shoreline-hq/).

node types.ts            # run a .ts file: Node strips the types, checks nothing
npx tsc -b               # shoreline-hq: check every project in tsconfig.json
npm run build            # shoreline-hq: tsc -b && vite build

🔀 Unions, Literal Types and Narrowing

A union of objects that share a kind field (a discriminated union) lets each branch see exactly the fields of that case. The HQ uses kind, not status, so it never gets confused with EventStatus.

// What a screen can be doing: each member has its own "kind"
export type LoadState =
  | { kind: 'loading' }
  | { kind: 'failed'; message: string }
  | { kind: 'ready'; events: CleanupEvent[] }

function report(state: LoadState) {
  if (state.kind === 'loading') {
    return 'Loading cleanups...'
  }
  if (state.kind === 'failed') {
    return `Could not load cleanups: ${state.message}`
  }
  return `${state.events.length} cleanups loaded`
}

📦 Modules and Checking Outside Data

Data from the API is unknown until a check proves its shape. A type predicate (value is T) is a function that does that check and tells TypeScript about it.

/** An object (not null, not an array), so its properties can be read */
function isRecord(value: unknown): value is Record<string, unknown> {
  return typeof value === 'object' && value !== null && !Array.isArray(value)
}

const eventStatuses: EventStatus[] = ['draft', 'scheduled', 'completed', 'cancelled']

export function isEventStatus(value: unknown): value is EventStatus {
  return eventStatuses.some((status) => status === value)
}

/** A check for one item becomes a check for a list of them */
function isListOf<T>(isT: (value: unknown) => value is T) {
  return (value: unknown): value is T[] => Array.isArray(value) && value.every(isT)
}

/** GET a path and check the JSON with a type predicate before anyone uses it */
export async function getJSON<T>(
  path: string,
  isT: (value: unknown) => value is T,
  signal?: AbortSignal,
): Promise<T> {
  const data = await apiFetch(path, signal)
  if (!isT(data)) {
    throw new Error(`Unexpected data from GET /api${path}`)
  }
  return data
}

A custom error class keeps its fields written out (parameter properties such as constructor(readonly status: number) are refused by erasableSyntaxOnly). Lesson 4.1.

/** The API answered, but with an error status (404, 500, ...) */
export class ApiError extends Error {
  readonly status: number
  readonly code: ErrorCode
  readonly fieldErrors: Record<string, string[]> | undefined

  constructor(status: number, body: ApiErrorBody) {
    super(body.message)
    this.name = 'ApiError'
    this.status = status
    this.code = body.error
    this.fieldErrors = body.fieldErrors
  }
}
