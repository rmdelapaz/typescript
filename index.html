🔷 React + TypeScript: Build a Modern Web App

React builds the screens; TypeScript checks every piece of data that flows through them, before your users ever see a bug. In eleven modules you learn both from the ground up and use them the way professional teams do, by building one real application from an empty folder to a tested, deployed app: Shoreline Crew HQ, where the organizers of a volunteer beach-cleanup group plan cleanups, manage sign-ups and show the difference they make. Then you build one of your own.

📚 About This Course

Most React jobs today are React and TypeScript jobs. TypeScript adds types to JavaScript: you describe the shape of your data once, and the compiler and your editor check every component, function and API call against it. Mistakes that would otherwise surface as a blank screen in production appear as a red underline while you type.

Every lesson explains why before how, uses code that was run and checked on the current tools, and ends with a project step for Shoreline Crew HQ, a short quiz and a learning journal prompt. If you fall behind, each lesson's starting and finished code is a download away.

What You'll Learn

  • TypeScript from the start: types and inference, object types, unions and narrowing, generics, utility types, and typing data you get from an API safely
  • React 19 with TypeScript: components and TSX, typed props, lists, state, events, forms with actions, and accessible, well-styled components
  • Effects and data fetching, custom hooks, refs, Suspense and error boundaries
  • Structuring a real app: reducers with discriminated unions, typed context, rendering performance and reusable component patterns
  • Routing with React Router 8, server state with TanStack Query, client state with Zustand (and how Redux Toolkit compares)
  • Forms at scale with React Hook Form and Zod: one schema for both the types and the validation
  • Testing with Vitest, React Testing Library, Mock Service Worker, Playwright and automated accessibility checks
  • Faster builds, a free deployment, and a pipeline that type-checks and tests every change

Who This Course Is For

  • You know JavaScript (variables, functions, arrays and objects, modules, async/await and fetch, a little DOM) and you are new to TypeScript and React
  • JavaScript developers who keep seeing "React + TypeScript" in job listings
  • Anyone planning to build mobile apps with React Native: this course is its prerequisite

✅ What you need before you start

Comfortable JavaScript and basic HTML and CSS. You do not need to know TypeScript or React: Module 2 teaches the TypeScript you need before React appears, and every later lesson keeps teaching it in context. If your JavaScript is rusty, Front-End JavaScript covers what this course assumes.

💡 Where this course leads

It is the prerequisite for React Native & Expo, where you build the volunteers' phone app for the same Shoreline Crew API, reusing the types, data layer and testing habits from here. If you would rather use WordPress as your back end, React + WordPress: Build a Headless Website is the sibling course.

🌊 What You'll Build

Shoreline Crew is a (fictional) volunteer group that cleans up six beaches on its stretch of coast. Its organizers need one place to run everything. You build it: Shoreline Crew HQ, a single-page web app that talks to a small typed API the course gives you.

  • Cleanups: a searchable, filterable list of cleanup events, a page for each, and forms to create and edit them, with validation messages people understand
  • Volunteers: rosters and sign-ups, a waiting list when a cleanup is full, and check-in on the day
  • Sign-in with roles: organizers can change things; volunteers can only see what they should
  • Impact: a dashboard of what the crew collected (weight, bags, debris types) with a simple chart, impact reports with photos, and a CSV export
  • Quality: tests at every level, accessibility checks, a fast production build and a deployment
  • Your own app (Module 11): plan, type, build, test and ship an app from a brief you choose

🧭 Where You'll Work

Everything in this course is free. Each lesson tells you where it happens:

  1. Your browser (Lesson 1.1): your first TypeScript runs in the TypeScript Playground, with nothing to install.
  2. Node.js and VS Code on your computer (from Lesson 1.2): the current long-term-support version of Node.js runs the tools and the API; VS Code shows TypeScript's errors as you type. Windows, macOS and Linux all work.
  3. The Shoreline Crew API on your computer (from Lesson 1.2): a folder you download and start with one command; it keeps running in its own terminal while you build.
  4. A free static host and GitHub (Lesson 10.2): the finished app goes live on Netlify, with GitHub Actions checking types and tests on every push.
