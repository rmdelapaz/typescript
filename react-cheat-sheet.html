📡 Effects and Fetching

Fetching in an effect, from the Module 4 stage (TanStack Query took over in 7.1): an AbortController cancels the request when the page goes away or the effect runs again, and an unknown error is described for people. Lesson 4.1.

export function SitesPage() {
  const [state, setState] = useState<LoadState<Site[]>>({ kind: 'loading' })

  // After the first render: ask the API for the sites, and cancel the request if the page goes away
  useEffect(() => {
    const controller = new AbortController()
    getSites(controller.signal)
      .then((sites) => setState({ kind: 'ready', data: sites }))
      .catch((error: unknown) => {
        if (controller.signal.aborted) return
        console.error(error)
        setState({ kind: 'failed', message: describeError(error) })
      })
    return () => controller.abort()
  }, [])

🪝 Custom Hooks

A custom Hook is a function whose name starts with use and that calls other Hooks. Call Hooks at the top of a component or Hook, never after an early return or inside an if. Lesson 4.2.

/** The value, but only once it has stopped changing for `delay` milliseconds */
export function useDebouncedValue<T>(value: T, delay: number): T {
  const [settled, setSettled] = useState(value)

  useEffect(() => {
    const timer = setTimeout(() => setSettled(value), delay)
    return () => clearTimeout(timer)
  }, [value, delay])

  return settled
}

useApi, from the Module 4–6 stages (TanStack Query replaced it in 7.1): a key that says what to load, a function that says how, and useEffectEvent so the function itself never belongs in the dependency array. Lesson 4.2.

export function useApi<T>(key: string, load: (signal: AbortSignal) => Promise<T>): ApiResult<T> {
  const [state, setState] = useState<LoadState<T>>({ kind: 'loading' })
  const [attempt, setAttempt] = useState(0)
  // The latest load function, without making the effect run again when it changes
  const loadLatest = useEffectEvent(load)

  useEffect(() => {
    const controller = new AbortController()
    loadLatest(controller.signal)
    // ...
    return () => controller.abort()
  }, [key, attempt])

The HQ's dialog: render it to open it; it remembers the opener and gives the focus back when it closes. !dialog.open guards against Strict Mode running the effect twice. Lesson 4.3.

export function Dialog({ title, onClose, children }: DialogProps) {
  const dialogRef = useRef<HTMLDialogElement>(null)
  const openerRef = useRef<Element | null>(null)
  const titleId = useId()

  useEffect(() => {
    const dialog = dialogRef.current
    if (dialog === null) return
    if (!dialog.open) {
      openerRef.current = document.activeElement // remember where the focus was
      dialog.showModal() // focus moves into the dialog, the page behind it goes inert
    }
    return () => {
      // Closing: give the focus back to the control that opened the dialog
      const opener = openerRef.current
      if (opener instanceof HTMLElement) opener.focus()
    }
  }, [])

  return createPortal(
    <dialog ref={dialogRef} aria-labelledby={titleId} className={styles.dialog} onClose={onClose}>
      <h2 id={titleId}>{title}</h2>
      {children}
    </dialog>,
    document.body,
  )
}

⏳ Suspense, use() and Error Boundaries

use(promise) suspends until the promise settles; the nearest <Suspense fallback> shows meanwhile. The promise must be the same one on every render, so it is cached outside the component (4.4's temporary cache; TanStack Query's useSuspenseQuery does this from 7.1). Lesson 4.4.

const saved = new Map<string, Promise<CleanupEventDetail>>()

/** The cleanup with this id: the first call starts the request, later calls get the same promise */
export function eventPromise(id: string): Promise<CleanupEventDetail> {
  let promise = saved.get(id)
  if (promise === undefined) {
    promise = getEvent(id)
    saved.set(id, promise)
  }
  return promise
}

An error boundary is still a class component: static getDerivedStateFromError switches to a fallback component, and retry tries the children again. Lesson 4.4.

type ErrorBoundaryState = { failed: false } | { failed: true; error: unknown }

// React has no Hook for catching errors yet, so an error boundary is a class component.
export class ErrorBoundary extends Component<ErrorBoundaryProps, ErrorBoundaryState> {
  state: ErrorBoundaryState = { failed: false }

  // React calls this when a child throws while rendering; the result becomes the new state
  static getDerivedStateFromError(error: unknown): ErrorBoundaryState {
    return { failed: true, error }
  }

  // An arrow function keeps `this` pointing at the boundary when a button calls it
  retry = () => {
    this.props.onRetry?.()
    this.setState({ failed: false })
  }

  render() {
    if (this.state.failed) {
      const Fallback = this.props.fallback
      return <Fallback error={this.state.error} retry={this.retry} />
    }
    return this.props.children
  }
}

🌐 Typed Context

Start the context at undefined and read it through a Hook that throws outside its provider, so a missing provider is one clear error, not undefined everywhere. Keep the context and Hook in a .ts file and the provider in a .tsx (Fast Refresh: only-export-components). Lesson 5.2.

// undefined is the value outside an AuthProvider: a mistake that useAuth() reports at once

/** The sign-in state. Only works inside <AuthProvider>. */

/** /events/:eventId: the cleanup must be in the cache before the page shows */
export async function eventLoader({ params }: LoaderFunctionArgs) {
  const { eventId } = params
  if (eventId === undefined) {
    throw new Error('eventLoader needs a route with an :eventId parameter')
  }
  // The page builds the same key from these two values
  const viewer = viewerId(readSession())
  try {
    await queryClient.query({ ...eventQuery(eventId, viewer), staleTime: 'static' })
  } catch (error: unknown) {
    if (error instanceof ApiError && error.status === 404) {
      const message = 'There is no cleanup at this address. The link may be wrong, or the cleanup is not public.'
      throw data(message, { status: 404, statusText: 'Cleanup not found' })
    }
    throw error
  }
  return { eventId, viewer }
}

export const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      // An answer counts as fresh for 30 seconds: no new request for it in that time
      staleTime: 30_000,
      // Try again after a network or server failure, but never after 401, 403 or 404:
      // asking again will not change those answers
      retry: (failureCount, error) =>
        !(error instanceof ApiError && error.status < 500) && failureCount < 2,
    },
  },
})

An optimistic update: cancel refetches, remember the old value, show the new one, roll back on error, and ask the API for the truth either way. Lesson 7.2.

  return mutationOptions({
    mutationFn: ({ signupId, mark }: MarkChange) =>
      patchSignup(signupId, { status: markStatus(mark) }),
    // Runs before the request: show the change now, and remember what to put back
    onMutate: async ({ signupId, mark }) => {
      // A refetch already on its way would overwrite the new mark with the old answer
      await queryClient.cancelQueries({ queryKey })
      const before = queryClient.getQueryData(queryKey)?.find((entry) => entry.id === signupId)?.status
      setStatus(signupId, markStatus(mark))
      return { before }
    },
    // The API said no (or could not be reached): put the old status back
    onError: (_error, { signupId }, saved) => {
      if (saved?.before !== undefined) {
        setStatus(signupId, saved.before)
      }
    },
    // Either way, ask the API for the truth: the roster, the spots left, a waiting list that moved up.
    // ...
    onSettled: () =>
      Promise.all([
        queryClient.invalidateQueries({ queryKey: ['events'] }),
        queryClient.invalidateQueries({ queryKey: ['volunteers'] }),
      ]),
  })
