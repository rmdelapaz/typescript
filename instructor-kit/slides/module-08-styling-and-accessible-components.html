3.6 · Where styles live

One stylesheet stops scaling

  • One namespace: two .card rules mix, nothing warns
  • No link to the component: delete it, its rules stay
  • Strings tsc cannot check: className="badge-sucess"
  • Approaches: global, CSS Modules, inline, Tailwind, CSS-in-JS
CHOICE The course uses CSS Modules: plain CSS, scoped by Vite, nothing extra in the browser.

3.6 · Variants

A union picks the class

shoreline-hq/src/components/Badge.tsx
import styles from './Badge.module.css'

export type BadgeTone = 'info' | 'success' | 'neutral' | 'danger'

interface BadgeProps {
  label: string
  tone?: BadgeTone
}

export function Badge({ label, tone = 'info' }: BadgeProps) {
  return <span className={`${styles.badge} ${styles[tone]}`}>{label}</span>
}
WHY styles[tone]: one class per member of the union. A typo in a template literal writes "undefined".
