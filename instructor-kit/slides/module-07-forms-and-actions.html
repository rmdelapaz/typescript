3.5 · Mental model

The sign-up sheet and the clipboard

  • Controlled: the clipboard; every change goes through state
  • Uncontrolled: the sheet; read it when it is handed in
  • Controlled for live values: search, counters
  • Uncontrolled + an action for fill-in-and-submit forms
RULE After an action, React RESETS the form: fields go back to defaultValue.

3.5 · Project Step 3

Selects and the reset (React 19.3)

  • A select reads its defaultValue only when it is created
  • After the reset it goes back to the first value it had
  • key={values.siteId}: a new key makes a new select
  • Inputs, textareas and checkboxes follow the newest defaultValue
