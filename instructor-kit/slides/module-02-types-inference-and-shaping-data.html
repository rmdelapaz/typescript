Every code is a question

RULE An error is a question, not a verdict.

2.2 · The ! assertion

A promise TypeScript cannot check

  • Honest: getElementById('root')! (your own index.html)

  • enum from an old tutorial? A union instead
RULE Possibly null is good news: a crash that did not happen.
