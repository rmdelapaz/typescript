10.1 · Warning

Splitting is for speed, not for secrets

  • A guest's link to /events/e08/edit downloads the edit page's file
  • Then the guard sends them to sign in
  • Anyone can read every file the build makes
  • Guards decide what a person sees; the API what anyone may do
10.1 · React.lazy

For a heavy widget inside a page

  • lazy(async () => ({ default: (await import(...)).ImpactChart }))
  • Named export? Map it to default (else TS2322)
  • Call it at the top level, never inside a component
  • Starts when React renders: data, then code (a waterfall)

10.1 · CSV

Typed and formula-safe

  • CsvColumn<Row>: a heading and value(row)
  • Commas, quotes, line breaks: inside "…", quotes doubled
  • Lines end with CRLF (RFC 4180)
  • Text starting with = + - @: a ' in front
