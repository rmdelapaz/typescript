3.1 · Under the hood

TSX becomes function calls

import { jsxs as _jsxs } from "react/jsx-runtime";
const crewName = 'Shoreline Crew';
export function Greeting() {
    return _jsxs("h1", { className: "title", children: [crewName, " HQ"] });
}
WHY Tags are values. Attributes are object properties. No import React needed.
3.1 · Rule 1

JavaScript's names

Property 'class' does not exist on type 'DetailedHTMLProps<HTMLAttributes<HTMLDivElement>, HTMLDivElement>'. Did you mean 'className'?
Property 'for' does not exist on type 'DetailedHTMLProps<LabelHTMLAttributes<HTMLLabelElement>, HTMLLabelElement>'. Did you mean 'htmlFor'?

3.1 · Rule 2

One parent, or a fragment

  return (
    <h2>Pelican Point Beach</h2>

}
src/Scratch.tsx:3:5 - error TS2657: JSX expressions must have one parent element.

WHY A function returns one value. <>… adds nothing to the page.
3.1 · Rules 3 and 4

Close every tag; braces hold expressions

  • <img … />, <br />, <Header />: every element closed
  • {title.toUpperCase()}, {capacity - spotsTaken}, {full ? a : b}
  • No if, for or const inside braces: put them above the return
  • Comments: {/* … */} · a space at a line end: {' '}
