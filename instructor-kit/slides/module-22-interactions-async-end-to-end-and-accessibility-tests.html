9.2 · Waiting

findBy, waitFor, getBy

  • await screen.findByRole(...): an element the API brings
  • await waitFor(() => expect(...)): not an element (a call, a Hook)
  • getBy after an awaited action: what changed at once
  • Retries off in tests: retry: false (else: fails after about a second)

9.3 · Mental model

The dress rehearsal

9.3 · Five ideas

Playwright in one slide

  • Fixtures: async ({ page, request }) => …
  • Locators: page.getByRole('link', { name }), strict
  • Actions wait: no findBy to remember
  • Web-first assertions retry: await expect(locator).toBeVisible()
  • The config: baseURL, webServer, workers
9.3 · Live demo

A guest finds a cleanup

shoreline-hq/e2e/browse.spec.ts
test('a guest finds a cleanup by searching', async ({ page }) => {
  await page.goto('/')
  await page.getByRole('navigation', { name: 'Main' }).getByRole('link', { name: 'Events' }).click()
  await expect(page.getByRole('heading', { level: 1, name: 'Cleanup events' })).toBeVisible()

  await page.getByLabel('Search cleanups').fill('pelican')
  await expect(page.getByText('Found 3 cleanups: 1 coming up, 2 in the log.')).toBeVisible()
  await expect(page).toHaveURL(/\?q=pelican$/)

  await page.getByRole('link', { name: 'Pelican Point Beach Sweep' }).click()
  await expect(page.getByRole('heading', { level: 1 })).toHaveText('Pelican Point Beach Sweep')
  await expect(page.getByRole('heading', { name: 'Where to meet' })).toBeVisible()
