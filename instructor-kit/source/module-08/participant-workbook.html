Lesson

3.6

Styling and Accessible Components

By the end you can
  • Explain why one global stylesheet stops scaling, and how CSS Modules scope class names to a component
  • Import a CSS Module in a typed component, combine classes, pick a variant from a union-typed prop, and read the string | undefined type TypeScript gives each class
  • Use inline style objects typed as CSSProperties for values that come from data, and know when not to
  • Self-host a font, keep design tokens global, and give every focusable element a visible focus ring
  • Check components for accessibility with the linter's jsx-a11y rules, the browser's audits, and a keyboard pass, and fix what only a person notices
Key ideas
  • CSS Modules: a file named Name.module.css; import styles from './Name.module.css' gives an object from your class names to unique generated ones (_note_1pozh_1). No clashes, no leftovers.
  • What TypeScript knows: every module is CSSModuleClasses (any string key); with noUncheckedIndexedAccess each class is string | undefined. A misspelled class compiles: look at the page (or write a declaration file, Exercise 3).
  • Names and variants: camelCase classes (.skipLink); combine with a template literal; pick a variant with a union-typed prop: styles[tone]. Sharing is importing another module (cardStyles).
  • Inline styles: an object typed CSSProperties (camelCase, numbers become px), only for values that come from data.
  • Tokens stay global: colors, the base font and the :focus-visible ring in index.css; a module can SET a token for everything inside it (--focus in the header). Fonts self-hosted with Fontsource.
  • Accessible components: the right element first, landmarks and headings, a name for every control that makes sense out of context, alt that describes or alt="", a visible focus ring, contrast and not color alone, ARIA only for state. Check with jsx-a11y, the browser's audits and your own keyboard.
Worked example: what TypeScript knows about a CSS Module

A helper that promises a string meets a CSS Module:

import styles from './Scratch.module.css'

// A helper that promises to return a string
function noteClass(): string {
  return styles.note
}

export function TideNote() {
  return <aside className={noteClass()}>High tide at 11:40</aside>
}

npx tsc -b:

src/Scratch.tsx:5:3 - error TS2322: Type 'string | undefined' is not assignable to type 'string'.
  Type 'undefined' is not assignable to type 'string'.

5   return styles.note
    ~~~~~~


Found 1 error in src/Scratch.tsx:5

Read it the Lesson 1.1 way: where (src/Scratch.tsx:5:3), what (TS2322: string | undefined into string), why: vite/client types every module as "any string key to a string", and noUncheckedIndexedAccess adds undefined to every read. In JSX, className accepts string | undefined, so className={styles.note} is fine.

And the other side: a misspelled class compiles. className={styles.ntoe} is undefined, React drops the attribute, and both tools stay silent. With npm run lint after npx tsc -b:

> shoreline-hq@0.0.0 lint
> oxlint

Found 0 warnings and 0 errors.

Glossary

TermMeaning
CSS ModuleA Name.module.css file whose class names are renamed to be unique to that file
CSSModuleClassesvite/client's type for a module: { readonly [key: string]: string } (any key)
index signatureA type for "any key of this kind"; with noUncheckedIndexedAccess each read may be undefined
design tokenA named value in :root (--link, --focus) that every component uses; inherited, so a module can set it for its subtree
side-effect importimport '@fontsource-variable/outfit': runs a file for what it does, not for what it exports
CSSPropertiesReact's type for a style object: camelCase properties, numbers become pixels
accessibility (a11y)Whether people who use a keyboard, a screen reader, zoom or voice control can use the app
accessible nameWhat assistive technology calls a control (a button's text, a field's label)
:focus-visibleMatches when the browser judges a focus ring helpful: keyboard focus, text fields
visually hidden textText in the page for screen readers, clipped to a 1-pixel box so it takes no room
jsx-a11yoxlint's plugin with the accessibility rules for HTML elements and ARIA in TSX
WCAGThe Web Content Accessibility Guidelines: contrast 4.5:1 for text, 3:1 for focus rings and borders
