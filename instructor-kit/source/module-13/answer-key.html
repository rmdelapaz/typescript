Session 13 12 self-check items Confidential

Warm-up: Session 12 Retrieval

  1. EventDetails reads the cleanup with use(). Why does it go through eventPromises.ts instead of calling getEvent(id) itself? use() needs the SAME promise on every render; a new getEvent() call would suspend again and start over. The module keeps one promise per cleanup.
  2. On the event page, what does the ErrorBoundary catch that the Suspense boundary does not? A rejected promise (or any error while rendering): Suspense only shows a fallback while the promise is pending; the boundary shows EventProblem when it fails (404 → Cleanup not found).
  3. The desk dispatches { type: 'checkIn', signupId } for a row that is already marked attended. What should the reducer return, and why? The SAME state object: nothing changed, so React can skip the render, and Undo gets no empty step.
  4. What does assertNever(value: never) in a switch's default give you? A compile error the day someone adds an action or a union member without a case, and a loud error if an unexpected value arrives at run time.

import { useEffect, useState } from 'react'
import { isSite } from './isSite.ts'
import type { LoadState } from './loadState.ts'
import type { Site } from './types.ts'

/** One site from the API, loaded when the component appears and again whenever siteId changes */
export function useSite(apiUrl: string, siteId: string): LoadState<Site> {
  const [state, setState] = useState<LoadState<Site>>({ kind: 'loading' })

  useEffect(() => {
    const controller = new AbortController()
    fetch(`${apiUrl}/api/sites/${encodeURIComponent(siteId)}`, { signal: controller.signal })
      .then(async (response) => {
        if (!response.ok) {
          setState({ kind: 'failed', message: `Could not load the site (${response.status}).` })
          return
        }
        const data: unknown = await response.json()
        if (!isSite(data)) {
          setState({ kind: 'failed', message: 'The API sent something that is not a site.' })
          return
        }
        setState({ kind: 'ready', data })
      })
      .catch((error: unknown) => {
        if (controller.signal.aborted) return     // we cancelled it: nothing went wrong
        console.error(error)
        setState({ kind: 'failed', message: 'Could not reach the server.' })
      })
    return () => controller.abort()
  }, [apiUrl, siteId])

  return state
}
import { assertNever } from './assertNever.ts'

export type BagKind = 'trash' | 'recycling'

/** The bag tally of one cleanup */
export interface TallyState {
  trash: number
  recycling: number
  /** the kinds in the order they were added, for undo */
  history: readonly BagKind[]
}

export const initialTally: TallyState = { trash: 0, recycling: 0, history: [] }

export type TallyAction = { type: 'add'; kind: BagKind } | { type: 'undo' } | { type: 'reset' }

// One more (or one fewer) bag of a kind
function counted(state: TallyState, kind: BagKind, change: 1 | -1): TallyState {
  return kind === 'trash'
    ? { ...state, trash: state.trash + change }
    : { ...state, recycling: state.recycling + change }
}

export function tallyReducer(state: TallyState, action: TallyAction): TallyState {
  switch (action.type) {
    case 'add':
      return { ...counted(state, action.kind, 1), history: [...state.history, action.kind] }
    case 'undo': {
      const last = state.history.at(-1)
      if (last === undefined) return state       // nothing to undo: the same state, so nothing renders
      return { ...counted(state, last, -1), history: state.history.slice(0, -1) }
    }
    case 'reset':
      return initialTally
    default:
      return assertNever(action)
  }
}

Exit Ticket

  1. AuthValue | undefined: outside a provider there is no sign-in. A fake default compiles and fails silently (signed out forever); undefined in the type makes the compiler force a check, which useAuth() does once, throwing "useAuth() must be used inside <AuthProvider>".
  2. Two files: Vite's Fast Refresh keeps a component's state only when its file exports components and nothing else; the context and its Hook go in AuthContext.ts, the provider in AuthProvider.tsx (oxlint's only-export-components warns otherwise).
  3. Who protects: the API. It sends drafts only with an organizer's token and answers 403 "Only organizers can do that." to a volunteer's roster request; the HQ only decides what is convenient to show.

Common Wrong Answers and What They Reveal

  • Q1 A. Has learned "context = shared" and applies it to a direct child. Show EventGroups' showDrafts prop: one level, explicit, clearer.
  • Q2 A or C. Reaches for a cast or a default: the two ways to keep the bug. Run the lesson's QuickSignIn outside a provider: nothing happens, and nothing says why.
  • Q5 B or D. Reads "no properties in common" as "remove it" or "cast it". Read RequestInit's properties aloud: all optional, signal among them.
  • Q6 A or C. Mixes up sending the token (request()) with WHEN to ask again (the dependency), or thinks the front end protects drafts.
  • Q7 A. Has not met Strict Mode's double effect run. Show the canceled request in the Network tab, then the build's single one.
  • Q10 A or C. Has not separated the promise from the component. Draw two renders, each creating its own promise.
