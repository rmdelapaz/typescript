Lesson

10.1

Performance and the Build

By the end you can
  • Read Vite 8's build output (chunks, sizes, gzip, hashed names) and explain what its 500 kB warning is telling you
  • Measure the JavaScript a visitor downloads, and find what is inside a bundle with a treemap
  • Split a React Router app with typed lazy routes, and use React.lazy with Suspense for a component
  • Shape the build's files with Rolldown's codeSplitting groups for better caching, without pulling lazy code back in
  • Protect the result with an end-to-end size budget, and add a typed, safe CSV export to the Impact page
Key ideas
  • The build (tsc -b && vite build, Rolldown): follows every import, drops unused code, minifies, writes hashed files to dist/. Two sizes: on disk (what the phone runs) and gzip (roughly what travels).
  • Measure, look, split, measure again: the Network tab on npm run preview (never the dev server), the treemap from npm run analyze.
  • Dynamic import makes a separate file. A route's lazy (function form, returns { Component }) downloads it with the loaders; React.lazy (needs { default }) downloads it when React renders: a waterfall.
  • Splitting is for speed, not for secrets: anyone can read every file; guards decide what a person sees, the API what anyone may do.
  • codeSplitting.groups decide which file a module lands in: a vendor file keeps its name across app changes (caching). A group that catches too much sends it to every visitor.
  • A budget test (no forms file, under 440 kB for a guest's tour) fails on any cause. CSV: RFC 4180 quoting, CRLF, and a ' in front of formula-looking text.

Glossary

TermMeaning
bundle, chunkThe files the build writes / one of those JavaScript files
RolldownVite 8's bundler
content hashThe part of a file name that changes when its content changes (safe to cache forever)
gzipCompression on the way; the browser unpacks and runs the full size
treemapA picture of the bundle: each box's area is its size (npm run analyze)
dynamic importimport('./x.tsx'): a Promise of the module, and a separate file
lazy routeA route's lazy: async () => ({ Component }): the page's file loads with its loaders
React.lazyA component loaded the first time it renders; needs { default } and a Suspense boundary
waterfallRequests that wait for each other (data, then code)
codeSplitting.groupsRules that decide which file a module lands in (a vendor file, a forms file)
performance budgetA limit a test enforces (here: bytes for a guest's tour)
CSV injectionText that a spreadsheet would run as a formula; defused with a leading '
