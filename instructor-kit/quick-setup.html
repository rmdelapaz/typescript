React + TypeScript: Build a Modern Web App · Quick Setup

Get Ready in About an Hour

Before the first session: install Node.js 24 or newer and VS Code, make your course folder shoreline, start the Shoreline Crew API, create Shoreline Crew HQ with Vite, and run the check. You need a laptop (Windows 10/11, macOS or Linux) with permission to install software. Do it at home. Stuck? The full Setup Guide covers every problem, the internet each session needs, the Session 24 accounts and joining at Part 2 or Part 3.

1 · Node.js (LTS, 24 or newer)

Windows / macOS: nodejs.org › LTS › the installer (.msi / .pkg), defaults. Linux: nvm, then nvm install --lts. In a new terminal:

node -v
npm -v

The Node version must start with v24 or higher.

2 · VS Code

  • Install VS Code (code.visualstudio.com; Windows: keep Add to PATH). If it does not already use TypeScript 7, add the TypeScript (Native Preview) extension; Oxc is optional.

3 · The course folder and the API

  • Make a folder shoreline (not in OneDrive, iCloud or Dropbox) and unzip shoreline-api.zip into it (from the course site or your instructor). shoreline/shoreline-api/server.ts must exist.
  • Open shoreline in VS Code (File › Open Folder…), then in the terminal (View › Terminal) start the API and leave it running:
cd shoreline-api
node server.ts

4 · Shoreline Crew HQ

In a second terminal, in shoreline (answer Enter, keep Oxlint, then No to install-and-start):

npm create vite@latest shoreline-hq -- --template react-ts
cd shoreline-hq
npm install

5 · Labs and the check

Copy the labs/ folder from your instructor into shoreline. With the API running, in the second terminal go back to shoreline (cd ..) and run:

node labs/module-01/l1_0-orientation/check_environment.mjs
✅ Done when the last line says READY for React + TypeScript: Build a Modern Web App

Send that line to your instructor. READY WITH NOTES is fine (read the CHECK lines). NOT READY? Fix the FIX lines from the top, run it again; still stuck: the Setup Guide's problems table, or bring the output to Session 1's install clinic.

If something goes wrong

You see…Try this
node "not recognized" / "command not found"Close every terminal (VS Code too) and open a new one.
PowerShell: "running scripts is disabled"Use Command Prompt, or Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
ERR_UNKNOWN_FILE_EXTENSION from node server.tsYour Node is too old: install the current LTS, then a new terminal.
FIX nothing answers at …Start the API: cd shoreline-api, node server.ts, leave it open.
Could not read package.jsonWrong folder: cd shoreline-hq first. Anything else: the Setup Guide, or the course's troubleshooting.html (rays-typescript.netlify.app).
