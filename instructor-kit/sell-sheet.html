Teach React + TypeScript: Build a Modern Web App

A ready-to-deliver course that takes JavaScript developers from their first type to a tested, deployed React + TypeScript app for a fictional beach-cleanup crew: components, data, routing, tests and CI.

26 × 3 h = 78 h 3 parts, each runs alone 35 lessons 312 self-checks

Who It's For

Learners who know JavaScript and are new to TypeScript and React: front-end developers, back-end developers moving to the front end, career changers. Prerequisites: JavaScript fundamentals (including modules and async/await), HTML and CSS; no TypeScript or React needed. Programs: trainers, bootcamps, colleges, corporate L&D, workforce programs.

  • Part 2 Data, State and Routing · 8 · 24 h
  • Part 3 Production React · 9 · 27 h
  • Two parts (1–2 or 2–3) · 17 sessions · 51 h
  • Every part ends in a project and assessment; Parts 2 and 3 open with a catch-up

What Learners Can Do After It

  • Type real data with unions, generics and guards
  • Build accessible components with state and forms
  • Fetch data, structure state, route with guards
  • Use TanStack Query, Zustand, React Hook Form and Zod
  • Test with Vitest, MSW and Playwright; ship with CI
  • Plan, build and present a client project of their own
