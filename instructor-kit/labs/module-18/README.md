# Session 18 labs: TanStack Query

Copy the kit's whole `labs/` folder into your course folder once (`shoreline/labs/`, next to `shoreline-api/`,
`shoreline-hq/` and `ts-lab/`), or copy just this `module-18/` folder into it. Work in the `starter/` folders;
`TASKS.md` in each lab says what to do and when you are done. Run every command from the folder named in the task.

| Folder | What it is | Needs |
|---|---|---|
| `l7_0-starting-with-part-3/` | Task 1: the catch-up check for anyone starting with Part 3 (your course folder from `lesson-24-start`); Tasks 2 and 3: a Parts 1 and 2 refresher on Node (a type predicate, a generic, a union) | the course folder and the API running for Task 1; `npm install` once in `starter/` |
| `l7_1-tanstack-query/` | a query factory, a component that reads a query, and a retry rule, tested with Vitest and MSW | `npm install` once in `starter/` (no API: MSW answers with real saved answers) |

`npm install` in a lab's `starter/` downloads that lab's packages into that folder only. Nothing here changes
`shoreline-hq`.
