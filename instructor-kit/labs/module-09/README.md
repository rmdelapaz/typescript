# Session 9 labs: Part 1 Project Check-in and Assessment

Session 9 teaches no new lesson. It is the check-in for the Part 1 project
(`labs/projects/part1-juniper-hill-garden/`, your copy next to the course app) and the Part 1 assessment.

| Folder | What it is | Needs |
|---|---|---|
| `part1-practical/` | the practical half of the Part 1 assessment (30 minutes, open book) | `npm install` once in `starter/` **before** Session 9 (at home): the room's Wi-Fi is not part of the test |

Install it at home: copy the folder, `npm install` in `starter/`, then `npm test` once (five tests fail with
`TODO`: that is how it should look). Do not start the tasks before the assessment.
