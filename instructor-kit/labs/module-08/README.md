# Session 8 labs: Styling and Accessible Components

Copy the whole `labs/` folder into your course folder once (`shoreline/labs/`), if you have not already. Work in
the `starter/` folders; `TASKS.md` says what to do and when you are done. Run every command from the folder the
task names (VS Code: right-click the folder > Open in Integrated Terminal).

| Folder | What it is | Needs |
|---|---|---|
| `l3_6-styling-and-accessible-components/` | a CSS Module with typed variants, a real button with a useful name, a style object typed as `CSSProperties` | `npm install` once in `starter/` |
| `../projects/part1-juniper-hill-garden/` | the Part 1 project (kickoff today, check-in in Session 9): its own `TASKS.md` and `RUBRIC.md` | `npm install` once in your copy of `starter/` |

`npm install` downloads React, Vitest, TypeScript and oxlint into that folder only. Nothing here changes
`shoreline-hq`, and nothing needs the API.
