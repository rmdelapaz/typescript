# Session 7 labs: Forms and Actions

Work in the `starter/` folder; `TASKS.md` says what to do and when you are done.

| Folder | What it is | Needs |
|---|---|---|
| `l3_5-forms-and-actions/` | a volunteer sign-up sheet: read FormData safely, check it with messages people understand, and a form with `useActionState` that keeps what was typed | `npm install` once in `starter/` |

Same packages as the other React labs (React 19.3, Vitest, Testing Library with user-event). No API and no server:
the form never sends anything. `npm test` RUNS the code; `npm run typecheck` CHECKS it. Nothing here changes
`shoreline-hq`.
