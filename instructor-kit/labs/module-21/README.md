# Session 21 labs: Testing Components (and Checkpoint 3)

Copy the whole `labs/` folder into your course folder once (`shoreline/labs/`), if you have not already. Work in
the `starter/` folders; each `TASKS.md` says what to do and when you are done. No API and no dev server needed.

| Folder | What it is | Needs |
|---|---|---|
| `checkpoint-3/` | Checkpoint 3 (Modules 7 and 8): a Zod form schema, a query factory and a mutation that invalidates, against tests you are given; plus four written questions in the workbook | `npm install` once in `starter/` (TanStack Query, Zod, Vitest, MSW) |
| `l9_1-testing-components/` | write unit and component tests for a volunteer thank-you card, a typed factory and a render helper, then prove them on planted bugs (`debug_*`) | `npm install` once in `starter/` (Vitest, jsdom, Testing Library) |

These labs never run inside `shoreline-hq`, and nothing here changes it. The lesson project (the HQ's first test
suite) is separate: it lives in `shoreline-hq/src/`.
