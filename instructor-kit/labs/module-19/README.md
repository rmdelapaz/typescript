# Session 19 labs: Mutations and Client State

Copy the kit's `labs/` folder into your course folder once (`shoreline/labs/`), or copy just this `module-19/`
folder into it. Work in the `starter/` folders; `TASKS.md` in each lab says what to do and when you are done.

| Folder | What it is | Needs |
|---|---|---|
| `l7_2-mutations/` | the volunteer's side of the crew: sign up for a cleanup, refresh what it changed, cancel a spot at once (and take it back if the API says no) | `npm install` once in `starter/` (no API: MSW plays shoreline-api, seeded with real answers) |
| `l7_3-client-state/` | pinned sites in a Zustand store that survives a reload and re-renders only the button that changed | `npm install` once in `starter/` |

Nothing here changes `shoreline-hq`.
