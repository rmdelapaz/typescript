# Session 6 labs: Lists, Conditional Rendering, State and Events

Work in the `starter/` folders; `TASKS.md` in each lab says what to do and when you are done. Run every command from
the folder named in the task.

| Folder | What it is | Needs |
|---|---|---|
| `l3_3-lists-and-conditional-rendering/` | a sorted list with keys and an empty state, a lookup table TypeScript keeps complete, a union drawn with a switch, the 0 trap | `npm install` once in `starter/` |
| `l3_4-state-and-events/` | state that must be copied, state lifted to a parent with a typed select, and a stored list that is always one keystroke behind | `npm install` once in `starter/` |

Both labs use the same packages as Session 5's lab (React, Vitest, Testing Library), so the second install is quick.
No API and no server: the data was saved from shoreline-api. `npm test` RUNS the components in a simulated browser;
`npm run typecheck` CHECKS them. Nothing here changes `shoreline-hq`.
