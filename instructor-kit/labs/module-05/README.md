# Session 5 labs: Props, Children and Composition

Copy the whole `labs/` folder into your course folder once (`shoreline/labs/`), if you have not already. Work in
the `starter/` folder; `TASKS.md` says what to do and when you are done. Run every command from the folder named in
the task (VS Code: right-click the folder > Open in Integrated Terminal).

| Folder | What it is | Needs |
|---|---|---|
| `l3_2-props-children-and-composition/` | typed props with a default, a component that takes children, and a tile composed from small pieces, on the six real beach sites | `npm install` once in `starter/` (no API, no server) |

`npm install` downloads React, TypeScript, Vitest and Testing Library into that folder only. Nothing here changes
`shoreline-hq`. `npm test` RUNS your components in a simulated browser (jsdom); `npm run typecheck` CHECKS them
(`tsc --noEmit`): you need both.
