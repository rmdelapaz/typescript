# Session 25 labs: Final Project Workshop and Next Steps

Copy the whole `labs/` folder into your course folder once (`shoreline/labs/`), if it is not there yet. Work in the
`starter/` folders; `TASKS.md` in each lab says what to do and when you are done.

| Folder | What it is | Needs |
|---|---|---|
| `l11_1-final-project/` | Types first on a brief that is NOT one of the seven: Bramblekey Piano Service. Domain types and label tables, values computed instead of stored, and a mock-API rule only the server can check, practised inside a fresh copy of the final-project kit's starter | `final-project-kit.zip` from Lesson 11.1, a copy of its `starter/` with `npm ci` done |
| `l11_2-next-steps/` | `satisfies` instead of `as`, a mapped, a conditional and a template literal type, and a declaration file for a JavaScript file that has none | `npm install` once in `starter/` |

Neither lab changes `shoreline-hq` or your own final project. Lab 11.1 runs in a practice copy of the starter that
you can delete afterwards; your final project starts from its own, clean copy.
