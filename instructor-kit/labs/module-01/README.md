# Session 1 labs: Why React + TypeScript and Your Workspace

Copy the whole `labs/` folder into your course folder once (`shoreline/labs/`, next to `shoreline-api/` and
`shoreline-hq/`). Work in the `starter/` folders; `TASKS.md` in each lab says what to do and when you are done.
Run every command from the folder named in the task (VS Code: right-click the folder > Open in Integrated Terminal).

| Folder | What it is | Needs |
|---|---|---|
| `l1_0-orientation/` | `check_environment.mjs` (is your computer ready?) and the diagnostic practice | the course folder; the API running for the check |
| `l1_1-why-react-typescript/` | describe real API data in TypeScript and read the compiler's errors | `npm install` once in `starter/` |
| `l1_2-your-workspace/` | running vs checking vs linting, plus a debug handout | `npm install` once in `starter/`; the API running for the handout |

`npm install` in a lab's `starter/` downloads TypeScript (and oxlint for Lab 1.2) into that folder only, like the
course app. Nothing here changes `shoreline-hq`.
