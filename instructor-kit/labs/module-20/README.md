# Session 20 labs: React Hook Form + Zod and Complex Forms

Copy the kit's `labs/` folder into your course folder once (`shoreline/labs/`), or copy just this `module-20/`
folder into it. Work in the `starter/` folders; `TASKS.md` in each lab says what to do and when you are done.

| Folder | What it is | Needs |
|---|---|---|
| `l8_1-react-hook-form-zod/` | a "join the crew" form: one Zod schema for its rules and types, React Hook Form for the form, the API's field messages under the fields | `npm install` once in `starter/` (no API) |
| `l8_2-complex-forms/` | a supply checkout: a list of rows people add and remove, a rule about the whole list, a file check | `npm install` once in `starter/` |

Nothing here changes `shoreline-hq`.
