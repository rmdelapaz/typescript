🔷 React + TypeScript: Build a Modern Web App: Course Syllabus

An instructor-led course in 26 three-hour sessions, in three parts that can each run on their own. Learn the TypeScript you need, then React in TypeScript from the first component, connect a real app to its API with routing and typed state, and finish with server state, forms at scale, tests, a production build and a free deployment.

📚 Course Description

React draws the screen from your data; TypeScript checks every piece of that data before the code runs. Together they are how most professional front-end teams build web apps today, and the habit they teach, describing the data first and letting the tools hold you to it, carries over to React Native, Next.js and Node.js on the server.

Every command and every listing in the course was run on Node.js 24 LTS (and checked on 26) with TypeScript 7.0, React 19.3, Vite 8, React Router 8, TanStack Query 5, React Hook Form with Zod 4, Vitest 5, MSW 3 and Playwright, and the project code of every lesson is checked against its real files. One project runs through every lesson: Shoreline Crew HQ, the organizers' web app of a fictional volunteer beach-cleanup group, built against a small typed mock API that runs on your own computer.

🎯 By the end you will be able to

  • Explain what React and TypeScript each do, when TypeScript's checks happen and what they cannot catch
  • Type real data with inference, object types, unions, narrowing, generics and checked API responses
  • Build React components in TypeScript with typed props, children, lists, state, events, forms and accessible styling
  • Fetch and structure data with effects, custom hooks, refs, Suspense, error boundaries, reducers and typed context
  • Route a single-page app with React Router 8: search params, nested routes, loaders, actions and protected routes
  • Manage server and client state with TanStack Query and Zustand, and build forms at scale with React Hook Form and Zod
  • Test with Vitest, Testing Library, MSW and Playwright, tune the build, and deploy for free with CI

Each part runs on its own: Part 1 (Sessions 1 to 9, 27 class hours, 12 lessons) takes you from no TypeScript to a typed React app with forms; Part 2 (Sessions 10 to 17, 24 hours, 11 lessons) connects it to its API with hooks, typed state and routing; Part 3 (Sessions 18 to 26, 27 hours, 12 lessons) adds server state, forms at scale, tests, the build and a deployment. Parts 2 and 3 open with a refresher and the catch-up code.

✅ Prerequisites

  • JavaScript fundamentals: variables, functions, arrays and objects, modules, async/await and the DOM; basic HTML and CSS. No TypeScript or React experience needed (Module 2 teaches the TypeScript you need before React appears).
  • A Windows 10/11, macOS or Linux laptop on which you may install software (Node.js and VS Code), with 8 GB of memory or more and a few gigabytes of free disk space.
  • The workspace is set up at home before Session 1, following Lesson 1.2: Node.js LTS, VS Code, the course's mock API (shoreline-api, no installation) and a Vite react-ts project. Session 1 has an environment check and an install clinic.
  • Starting with Part 2 or Part 3 only: the earlier parts or equivalent experience (Part 2: TypeScript basics and React components, state, events and forms; Part 3: a typed React app with fetching, context and routing). Each part opens with a refresher and the catch-up code.

💡 Format

26 sessions × 3 hours = 78 class hours, one or two lessons per session (Sessions 9, 17, 26 teach no new lesson: project check-ins, assessments and the showcase; Sessions 4, 5, 7, 8, 10, 13, 16, 18, 21, 23, 24 teach one lesson each and give the rest of the time to a checkpoint or project work), in three parts: Part 1, TypeScript and React Foundations (Sessions 1 to 9), Part 2, Data, State and Routing (Sessions 10 to 17) and Part 3, Production React (Sessions 18 to 26). Every lesson on the course site is written for a solo learner and takes about 115 to 160 minutes, so two lessons do not fit whole in one room session. The room protects what is hardest alone: the mental model, a live demo you type along with, a guided lab with help on hand, and starting each lesson project. At home you finish the projects and do each lesson's exercises, quiz and journal entry on the free course site: about two to three hours between sessions.

Each session runs 0:00 to 3:00: a warm-up on last session, the first lesson, a 10-minute break, the second lesson (or the rest of a one-lesson session), and a wrap-up with an exit ticket and the next bring list. One-lesson sessions add a checkpoint or project time; Sessions 9, 17 and 26 are project check-ins, assessments and the showcase.

🏁 Checkpoints, Assessment and Project

  • Self-checks and exit tickets in every session are practice, not grades: they tell you and your instructor what to revisit.
  • Checkpoint 1 (Session 4), Checkpoint 2 (Session 13) and Checkpoint 3 (Session 21), 30 minutes each: short individual tasks on the modules just finished, scored with a short rubric.
  • Part 1 project and assessment (Sessions 8 and 9): a typed domain, components, state and events and a form with actions, for a fictional client, plus an individual assessment on Modules 1 to 3, scored with rubrics.
  • Part 2 project and assessment (Sessions 16 and 17): fetching from a small mock API, routing, context or a reducer and one protected route for another client, plus an assessment on Modules 4 to 6.
  • Final project (Sessions 25 and 26). From a brief, you plan, type, build, test and ship your own app, present it and review a classmate's. A well-reasoned modest project scores as well as an elaborate one. The course is complete when the final project is complete under its rubric and the written final assessment is passed (70 %).

🧰 Required Software and Data

  • Node.js: the current LTS release, 24 or newer (the course was checked on 24 and 26), with npm
  • A code editor: VS Code (free), with TypeScript's errors in the editor; the Oxc extension is optional
  • The course API: shoreline-api, a free download that runs with one command (no install, no account)
  • A browser: a current Chromium browser (Chrome, Edge) or Firefox, with its developer tools
  • Accounts (Part 3 only): a free GitHub account and a free Netlify account for the deployment in Session 24; no paid tools, no real deployment required to pass

The workspace is set up once, at home, before Session 1, following Lesson 1.2 (Node.js LTS, VS Code, the course API and a Vite react-ts project). Your instructor sends a setup guide and an environment check a week ahead; Session 1 has an install clinic for anything that went wrong. Learners starting with Part 2 or Part 3 get the catch-up code from the course downloads.
